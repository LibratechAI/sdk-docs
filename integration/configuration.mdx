---
title: "What you can configure"
description: "See what your product can change in the SDK, what Libra sets for you, and what stays fixed."
---

Your product configures the SDK in `Libra.init()` and with a few methods. Some behavior is set by Libra for your product or the user's account, and some can't be changed. Each row links to the page that explains it in full.

To try the options without writing code, use **Init config** in the [Playground](/integration/playground): change the product, research sources, locale, `zIndex`, and `onClose`, then copy the matching `Libra.init()` call.

## Set in your code

| What you decide | Use | If you don't set it | Details |
| --- | --- | --- | --- |
| Which product the integration represents | `productId` | Required | [API reference](/reference/overview) |
| Which research sources are selected when the chat opens | `researchSources` | None preselected; users can still choose | [Research sources](/capabilities/research-sources-and-citations) |
| Which Libra environment the SDK uses | `baseUrl` | `https://app.libratech.ai` | [Trusted origins](/integration/trusted-origins) |
| Whether users sign in through your own backend | `proxy` | Users sign in with the Libra popup | [Authentication](/integration/authentication) |
| Where the SDK window sits in your page | `attach()`, `mountTarget`, `zIndex` | Mounted on `document.body` with `z-index: 999999` | [Mounting and positioning](/integration/lifecycle#mounting-and-positioning) |
| Whether the Libra header with a close button appears | `onClose` | No Libra header | [Header ownership](/integration/lifecycle#header-ownership) |
| Which language the SDK uses | `locale`, `locales`, `setLocale()` | The browser's language if registered, otherwise `en-US` | [Locales](/integration/locales) |
| How your product reacts to sign-in and sign-out | `onAuthStateChange`, `onAuthError`, `signOut()` | No callbacks | [Authentication](/integration/authentication) |
| Whether citations open in your own viewer | `onCitationClick` | Citations open in a new tab | [Citation ownership](/integration/citation-clicks) |
| Whether to offer the document the user is viewing | `setSuggestedAttachment()`, `clearSuggestedAttachment()` | No suggestion | [Suggest an attachment](/integration/suggestions) |
| Whether to attach documents or files for the user | `addAttachments()`, `clearAttachments()` | Nothing attached | [Attach directly](/integration/add-attachments) |
| Which chat opens | `openChatById()` | The user's last active chat | [Navigation and handoffs](/integration/navigation-and-handoffs) |

<Warning>
**FAB index required.** Research documents you suggest or attach must already be in your product's FAB index. Libra checks the index but doesn't add documents to it. See [Availability boundary](/integration/attachments#availability-boundary).
</Warning>

## Set by Libra

These depend on your product's setup with Libra or on the user's account. Your code can't change them.

- **The contents of your FAB index.** Libra only checks it.
- **Which research sources a user can choose.** They follow the user's account and product access.
- **Legal software access.** The product must be enabled for the user's team, and the user needs a connection to it.
- **Document uploads.** Libra can turn them off for an account. The attachment options are then hidden, and host files aren't added.
- **SDK-only access.** Libra can limit an account to the SDK. **Continue in Libra** is then hidden, and other links to Libra Workspace are blocked.
- **Plans, limits, and account screens.** See [Sign-in and onboarding](/capabilities/sign-in-and-onboarding#account-screens).

To ask about these settings for your product, email [libra-integrations@wolterskluwer.com](mailto:libra-integrations@wolterskluwer.com) or post in the [Libra SDK Integration - Dev chat](https://teams.microsoft.com/l/channel/19%3Aae4937fe4c7a4c40b45fb2c9bf349505%40thread.tacv2/Libra%20SDK%20Integration%20-%20Dev%20chat?groupId=91f72c7b-9471-43fd-bfd7-3b870128f4b7&tenantId=8ac76c91-e7f1-41ff-a89c-3553b2da2c17) on Microsoft Teams. To request something new, use the [Product Requests & Feedback form](https://app.notion.com/p/Product-Requests-Feedback-277eb48252ec801685a5c40c98d3f50d).

## Not configurable

- **The look of the chat.** The SDK window is isolated from your page's CSS, so your styles can't change it, and its styles can't affect your page.
- **Chat features.** Chat modes, tools, Assistants, Workflows, and Projects follow the user's Libra account. See [Capabilities](/capabilities/overview).
- **The Document Viewer.** The SDK opens and positions it. See [Document Viewer integration](/integration/document-viewer).
