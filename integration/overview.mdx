The Libra SDK lets a host product embed Libra's chat experience in an isolated iframe. The host owns the surrounding product UI and chooses when and where the widget appears; the SDK owns the chat interface and its session.

This guide is for engineers and QA. To see what users experience first, read [Capabilities](/capabilities/overview).

## What the host provides

- A valid `productId` identifying the legal-research product.
- A host-owned open control and a visible target container.
- The surrounding panel or modal when the product uses one.
- The close behavior. Providing `onClose` enables the SDK header; the callback should hide the host wrapper and call `Libra.detach()`.
