---
title: "Suggest an attachment"
description: "Offer the document the user is viewing as a chip above the chat input."
---

Pass an `Attachment` to `Libra.setSuggestedAttachment()` after the session has started. The SDK shows a suggestion chip above the chat input. The attachment, including any nested `attachments`, is added only when the user selects the chip. A new call replaces the previous suggestion. See [Attachments and availability](/integration/attachments) for the attachment types.

<Tabs>
  <Tab title="Research product">
    ```ts
    import { Libra, type ExternalDocument } from '@libra/sdk';

    const document: ExternalDocument = {
    	id: 'case-1842',
    	title: 'Acme v. Northstar',
    	url: 'https://host.example.com/documents/case-1842',
    	source: 'wko_de',
    	attachments: [
    		{
    			id: 'case-1842-pdf',
    			title: 'Acme v. Northstar PDF',
    			url: 'https://host.example.com/documents/case-1842.pdf',
    			source: 'wko_de'
    		}
    	]
    };

    await Libra.setSuggestedAttachment(document);
    ```

    `id` is your document ID, and `source` is the research source that owns it.
  </Tab>
  <Tab title="Legal software">
    ```ts
    import { Libra, type ExternalDocument } from '@libra/sdk';

    const document: ExternalDocument = {
    	id: '9585',
    	title: 'Kaufvertrag.pdf',
    	url: 'https://kleos.example.com/documents/9585',
    	source: 'kleos'
    };

    await Libra.setSuggestedAttachment(document);
    ```

    `id` is the product's own document ID, and `source` is the legal software product.
  </Tab>
  <Tab title="Host file">
    ```ts
    import { Libra } from '@libra/sdk';

    // file is a File or Blob your product already holds.
    await Libra.setSuggestedAttachment({ file, title: 'Mandate agreement.pdf' });
    ```
  </Tab>
</Tabs>

<Warning>
**FAB index required.** A research document can be used only if it's already in your product's FAB index. Libra checks the index but doesn't add documents to it. Legal software documents and host files are indexed by Libra instead. See [Availability boundary](/integration/attachments#availability-boundary).
</Warning>

Call `Libra.clearSuggestedAttachment()` when the selection in your product is no longer relevant:

```ts
await Libra.clearSuggestedAttachment();
```

## What the user sees

- A chip labeled **+ [title]** appears above the chat input, with the main document's title. For a `HostFile`, the chip shows the file name with a generic document icon.
- While the chip is visible, Libra checks research documents against your FAB index in the background. The user doesn't see this check.
- When the user selects the chip:
  - If the group is available, every document in it that isn't already in the chat input is added.
  - If the check is still running, the chip shows a loading state and attaches the documents when the check succeeds.
  - If the group is unavailable, nothing is attached and a **Content unavailable** notice appears. If the check had already failed, the first selection shows that result without checking again; the next selection checks again.
  - A legal software document is linked into the user's active project and shows a loading state while Libra indexes it.
- The chip stays visible until every document in the group is in the chat input. A host file's chip hides while a file with that name is in the chat input.
- The suggestion isn't tied to one chat. When the user starts a new chat, the chip appears again until you clear it or the user attaches everything.
- A new `setSuggestedAttachment()` call replaces the chip. `clearSuggestedAttachment()` removes it; documents the user already attached stay in the chat input.

See [Current-document context](/capabilities/current-document) for screenshots.

## Deprecated suggestion methods

`Libra.setDocumentSuggestion()` and `Libra.clearDocumentSuggestion()` still work and forward to `setSuggestedAttachment()` and `clearSuggestedAttachment()`. Each logs a one-time deprecation warning in the console. Migrate to the new methods:

| Deprecated | Replacement |
| --- | --- |
| `setDocumentSuggestion(document)` | `setSuggestedAttachment(document)` |
| `clearDocumentSuggestion()` | `clearSuggestedAttachment()` |

To attach documents without a chip, see [Add attachments](/integration/add-attachments).
