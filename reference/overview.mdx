This page documents the public `@libra/sdk` contract for version `0.15.1` (source revision `12ecdcc36ef87c651750a19ebb93ab12cbda8421`), generated from the package's public declaration entry point `dist/index.d.ts`.

The reference does not expose internal iframe messages, viewer snapshots, storage shims, fetch interceptors, or application components.

## Public entry point

Import the SDK from the package or its versioned CDN bundle:

```ts
import { Libra } from '@libra/sdk';
```

The package exports `Libra` and the public types listed below. The npm package declares `dist/index.d.ts` as its type entry point and exposes locale subpaths under `@libra/sdk/locales/*`.

## Libra methods

| Method | Purpose | Lifecycle requirement |
| --- | --- | --- |
| `Libra.init(config)` | Create the SDK iframe and resolve configuration. | Call once after `document.body` exists. Call `destroy()` before reinitializing. |
| `Libra.attach(elementOrId)` | Reveal and position the widget over a host target and start the session on first attach. | The target must exist and have usable dimensions. |
| `Libra.detach()` | Hide the widget while preserving the active session. | Safe to call when temporarily hiding the widget. |
| `Libra.destroy()` | Remove the widget, listeners, viewer, and SDK resources. | Call `init()` again before the next attach. |
| `Libra.signOut()` | Ask the active session to sign out. | Requires an attached session. |
| `Libra.setSuggestedAttachment(attachment)` | Show a suggestion chip that attaches a host document or file, with any nested attachments, when the user clicks it. Replaces the previous suggestion. | Requires an attached session. |
| `Libra.clearSuggestedAttachment()` | Clear the current suggestion chip. | Requires an attached session. |
| `Libra.addAttachments(attachments)` | Attach host documents or files to the current chat input without a chip. | Requires an attached session. |
| `Libra.clearAttachments()` | Remove every host-provided attachment from the chat input. | Requires an attached session. |
| `Libra.setDocumentSuggestion(document)` | Deprecated. Forwards to `setSuggestedAttachment()` and logs a one-time warning. | Requires an attached session. |
| `Libra.clearDocumentSuggestion()` | Deprecated. Forwards to `clearSuggestedAttachment()` and logs a one-time warning. | Requires an attached session. |
| `Libra.setLocale(locale)` | Change the active registered locale. | Register the locale during `init()` or load its CDN bundle before `init()`. Requires an attached session. |
| `Libra.openChatById(chatId)` | Open an existing chat by its host-provided ID. | Requires an attached session; empty IDs are ignored. |

See [Lifecycle and configuration](/integration/lifecycle) and [Authentication](/integration/authentication) for lifecycle and configuration decisions. See [Host integrations](/integration/host-integrations) and [Locales](/integration/locales) for implementation examples.

## Configuration

`Libra.init()` accepts `LibraConfig`. The public options are:

- `productId` identifies the broader host product and is required.
- `researchSources` pre-selects granular research sources.
- `baseUrl` selects the Libra environment and defaults to `https://app.libratech.ai` outside proxy mode.
- `proxy` routes API requests through a host-owned BFF.
- `mountTarget` selects the host element that owns the SDK wrapper.
- `zIndex` controls the wrapper's stacking order.
- `locale` selects the initial registered locale.
- `locales` supplies additional `LibraLocaleBundle` values.
- `onClose` handles the SDK header close action.
- `onAuthStateChange` receives authentication state changes.
- `onAuthError` receives interactive authentication failures.
- `onCitationClick` can claim supported citation navigation with `preventDefault()`.

The exact field types are in the package's `dist/index.d.ts`. The current behavioral constraints are documented in [Embedding and layout constraints](/integration/embedding-constraints), [Trusted origins](/integration/trusted-origins), and [BFF and proxy authentication](/integration/bff-authentication).

## Reference status

The public contract overview is source-checked against `@libra/sdk@0.15.1`, source revision `12ecdcc36ef87c651750a19ebb93ab12cbda8421`, and the generated public entry-point surface. Compared with `0.14.1`, `0.15.0` added the attachment methods, the `Attachment`, `HostFile`, `ResearchProductId`, `LegalSoftwareProductId`, and `LegalSoftwareSourceId` types, and deprecated the document suggestion methods; `0.15.1` did not change the public API. `LibraConfig` is unchanged. The reference covers the shipped `Libra` methods, configuration fields, callbacks, and exported types without presenting internal implementation details as public API.
