The reviewed SDK baseline is `@libra/sdk@0.15.1`. See the [Changelog](/changelog) for release notes and the [API reference](/reference/overview) for the public contract.

## Current limitations

- Available tools, research sources, Assistants, Projects, uploads, and account-state flows depend on product configuration, entitlements, indexing, and the active environment.
- The host owns document identity, permissions, product-owned navigation, and any BFF or proxy recovery flow.
- The SDK-managed document viewer and generated-document behavior are integration surfaces, not standalone host APIs. Do not depend on internal iframe messages, frame selectors, or viewer protocols.
- Staging behavior and CDN availability do not by themselves prove application production promotion. Confirm the exact environment and version before release.

## Support

For integration questions, email [libra-integrations@wolterskluwer.com](mailto:libra-integrations@wolterskluwer.com) or post in the [Libra SDK Integration - Dev chat](https://teams.microsoft.com/l/channel/19%3Aae4937fe4c7a4c40b45fb2c9bf349505%40thread.tacv2/Libra%20SDK%20Integration%20-%20Dev%20chat?groupId=91f72c7b-9471-43fd-bfd7-3b870128f4b7&tenantId=8ac76c91-e7f1-41ff-a89c-3553b2da2c17) channel on Microsoft Teams. Include the SDK version, environment URL, browser, reproduction steps, and any relevant correlation ID from the host BFF.

For product requests and feedback, use the [Product Requests & Feedback form](https://app.notion.com/p/Product-Requests-Feedback-277eb48252ec801685a5c40c98d3f50d).
