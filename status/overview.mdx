The reviewed SDK baseline is `@libra/sdk@0.16.0`. See the [Changelog](/changelog) for release notes and the [API reference](/reference/overview) for the public contract.

## Versions

- **0.x releases are ready for production.** The version number doesn't mean the SDK is a preview.
- **A minor release can break the API.** Breaking changes are marked **BREAKING** in the [Changelog](/changelog); read it before you upgrade.
- **Older SDK versions keep working with Libra.** If an update to Libra breaks an older SDK version, report it as a bug.
- **The package is on npm and the CDN.** The npm package comes from the Wolters Kluwer Artifactory registry and includes an ES module, a UMD build for `require`, and TypeScript declarations. The CDN serves each version at `https://cdn.wolterskluwer.io/wk/libra-sdk/<version>/`. See the [Quickstart](/integration/quickstart).

## Current limitations

- Available tools, research sources, Assistants, Projects, uploads, and account-state flows depend on product configuration, entitlements, indexing, and the active environment.
- The host owns document identity, permissions, product-owned navigation, and any BFF or proxy recovery flow.
- The SDK-managed document viewer and generated-document behavior are integration surfaces, not standalone host APIs. Do not depend on internal iframe messages, frame selectors, or viewer protocols.
- Staging behavior and CDN availability do not by themselves prove application production promotion. Confirm the exact environment and version before release.
