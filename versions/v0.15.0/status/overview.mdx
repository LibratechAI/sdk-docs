The reviewed SDK baseline is `@libra/sdk@0.15.0`. See the [Changelog](/versions/v0.15.0/changelog) for release notes and the [API reference](/versions/v0.15.0/reference/overview) for the public contract.

## Current limitations

- Available tools, research sources, Assistants, Projects, uploads, and account-state flows depend on product configuration, entitlements, indexing, and the active environment.
- The host owns document identity, permissions, product-owned navigation, and any BFF or proxy recovery flow.
- The SDK-managed document viewer and generated-document behavior are integration surfaces, not standalone host APIs. Do not depend on internal iframe messages, frame selectors, or viewer protocols.
- Staging behavior and CDN availability do not by themselves prove application production promotion. Confirm the exact environment and version before release.

## Support

For integration questions, contact [integration support](mailto:hi@mintlify.com) with the SDK version, environment URL, browser, reproduction steps, and any relevant correlation ID from the host BFF.

See the [Changelog](/versions/v0.15.0/changelog) for confirmed SDK releases and [Production readiness](/versions/v0.15.0/integration/production-readiness) for the release review checklist.
