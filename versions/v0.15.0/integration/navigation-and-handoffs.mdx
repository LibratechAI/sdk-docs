The SDK can open an existing Libra chat in the embedded session. Product navigation outside the chat remains host-owned.

## Open a chat by ID

Call `Libra.openChatById()` after `Libra.attach()` has started the session. The SDK trims the ID and ignores an empty value.

```ts
openSavedChatButton.addEventListener('click', async () => {
	await Libra.openChatById('chat-1842');
});
```

The method sends the chat ID to the embedded Libra application. The host should validate that the ID belongs to the signed-in user before presenting it as a product action.

## Citation handoffs

Use `onCitationClick` when a host viewer or main application should own research-source navigation. Claim only the sources your host can resolve, and leave the rest untouched so the SDK opens them in a new tab. See [Citation ownership](/versions/v0.15.0/integration/host-integrations#citation-ownership) for the payload, example, and checklist.

## Main-app and generated-document handoffs

<Note>
The current public SDK does not provide arbitrary main-app routing, generated-document handoff callbacks, or a general navigation API. Keep those routes and controls in the host application.
</Note>

The public `0.15.0` SDK exposes `openChatById()` and citation interception, but it does not expose a separate main-app navigation method or generated-document handoff callback. A host that needs those flows should keep the surrounding control and navigation in its own application, then use a normal host-owned link or action.

The `ExternalDocument.url` field is the navigation target for a suggested document chip. It is opened by the host or by the SDK's document-chip behavior according to the product flow; it is not a generated-document API. Do not document internal viewer messages or generated-document implementation details as supported host contracts.

## Ownership checks

- The host owns saved-chat controls and authorization for chat IDs.
- The host owns routes for product pages, document viewers, and generated documents.
- The SDK owns embedded chat navigation and the default behavior for unclaimed research citations.
- `preventDefault()` is the boundary that transfers an individual citation navigation to the host.

See [the Integration guide](/versions/v0.15.0/integration/overview) for lifecycle ordering and [host integrations](/versions/v0.15.0/integration/host-integrations) for document and citation contracts.
